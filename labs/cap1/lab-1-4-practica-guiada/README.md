# Laboratorio 1.4. Práctica guiada de mejora incremental de prompts

> **Enunciado marcador.** El título y la duración de este laboratorio son definitivos. Las
> secciones de Prerrequisitos, Pasos, Resultado esperado y Criterios de revisión están sin
> redactar y se completan en **SPEC-010**.

## Objetivo del laboratorio

Mejorar un prompt de forma incremental y usar los comandos del chat que existen en la
versión vigente de Visual Studio Code, para reconocer qué aporta cada elemento del prompt y
cuándo conviene un comando en lugar de un prompt escrito.

## Duración

30 minutos.
