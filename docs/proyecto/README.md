# Proyecto: reporte de comisiones por medio de pago

Aquí vive todo lo que el equipo produce al recorrer el ciclo de vida de una funcionalidad
nueva en el capítulo 5. El mapa de las fases está en [`CICLO-DE-VIDA.md`](../../CICLO-DE-VIDA.md).

| Ruta | Qué es |
|---|---|
| `backlog/` | Las solicitudes que llegan del negocio, tal como llegan |
| `plantillas/` | Plantillas de historia de usuario, estimación, registro de tiempos y notas de versión |
| `historia-reporte-medios-de-pago.md` | La historia de usuario con sus criterios de aceptación. La crea el 5.1 |
| `estimacion.md` | La estimación con y sin IA, por fase. La crea el 5.1 |
| `registro-de-tiempos.md` | La hora real de inicio de cada fase. Se completa del 5.1 al 5.4 |
| `pull-request.md` | La descripción del cambio con la plantilla de pull request. La crea el 5.3 |
| `notas-de-version-*.md` | Las notas de cada versión. Las crea el 5.4 |
| `incidentes/` | Los incidentes recibidos y su análisis. Se completa en el 5.4 |

Las decisiones de arquitectura van en [`docs/arquitectura/decisiones/`](../arquitectura/decisiones/README.md).
