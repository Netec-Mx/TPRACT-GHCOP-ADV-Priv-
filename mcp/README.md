# Servidor MCP local

> **Archivo marcador.** El servidor, sus herramientas y el procedimiento del laboratorio
> se construyen en **SPEC-006**. El directorio `servidor-local/` está vacío por ahora.

Este directorio contendrá un servidor de Model Context Protocol que corre como proceso
local y se comunica por entrada y salida estándar, sin ninguna salida a internet. Es el
material del laboratorio 3.4 y el ejemplo con el que se discuten los riesgos de seguridad
del capítulo 3.

La restricción de operar sin internet no es una simplificación del ejercicio: es el
requisito real del ambiente bancario donde este equipo tendría que usar MCP.
